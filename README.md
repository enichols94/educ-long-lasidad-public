# Education and longitudinal cognitive change in LASI-DAD

This repository contains the R analysis code for a study of education and
longitudinal cognitive change using LASI and LASI-DAD data. The analysis was
developed by Emma Nichols.

The repository contains code only. Controlled participant data, variable maps,
and two externally created simulation panels are not distributed here. Obtain
all required data through the relevant data custodians and comply with their
terms of use.

## Configuration

Run each script from `<PROJECT_ROOT>`. Configure the three controlled-data
locations in the R process environment using placeholder values such as:

```text
LASI_RAW_DIR=<PATH_TO_LASI_RAW_DATA>
HARMONIZED_DATA_DIR=<PATH_TO_HARMONIZED_DATA>
LASIDAD_EXIT_DIR=<PATH_TO_LASIDAD_EXIT_DATA>
```

Do not commit local environment settings. Repository-managed source inputs go
in `<SOURCE_DATA_DIRECTORY>`, intermediate objects go in
`<DERIVED_DATA_DIRECTORY>`, and figures and tables are written below
`<OUTPUT_DIRECTORY>`. These labels are placeholders, not real filesystem
locations.

### Required controlled-data files

The configured controlled-data directories must contain these files:

- `lasi_w1b_ind_bm.dta`
- `H_LASI_a3.dta`
- `h_dad_w1a3.dta`
- `dad_exit_clean.dta`

### Required user-provided files

Place the following files in `<SOURCE_DATA_DIRECTORY>`:

- `dad_tracker_v1.dta`
- `H_LASI_DAD_b1.dta`
- `H_DAD_w12_noimp_core.dta`
- `variable_map.xlsx`
- `practiceeffects_variable_map.xlsx`
- `Educ-cogdecline-sim1.jpg`
- `Educ-cogdecline-sim2.jpg`

The JPEG files are externally created conceptual panels. They are combined by
`052_simulation_plot.R` with the result plots generated by scripts `050` and
`051`.

## Software dependencies

Install R and the packages used by the scripts before beginning the analysis.
The shared setup code reports all missing packages and does not install
software automatically.

The package set includes `data.table`, `ggplot2`, `readr`, `haven`, `openxlsx`,
`dplyr`, `stringr`, `labelled`, `scales`, `gridExtra`, `lubridate`, `survival`,
`patchwork`, `survey`, `srvyr`, `pROC`, `Hmisc`, `weights`, `parameters`,
`forcats`, `geepack`, `lme4`, `lqmm`, `mice`, `miceadds`, `broom.mixed`,
`INLA`, `INLAjoint`, `quantreg`, `JM`, `doBy`, `paletteer`, `pbapply`,
`future.apply`, and `figpatch`. Some packages, particularly `INLA` and
`INLAjoint`, may require installation instructions from their maintainers.

## Analysis workflow

The scripts are numbered by analysis family, but one dependency requires script
`031` to run before script `030`:

```text
010 -> 011 -> 020 / 021 / 031 / 050 / 051
010 -> 012 -> 040
031 -> 030
050 + 051 + two user-provided JPEG panels -> 052
```

- `010_dataprep.R` combines the source datasets and creates `processed_data.rds`.
- `011_weights.R` calculates mortality and attrition weights and creates
  `processed_data_weights.rds`.
- `012_pe_weights.R` calculates practice-effect weights and creates
  `processed_practiceeffects_data.rds`.
- `020_descriptivetable.R` creates the descriptive table.
- `021_plottrajectories.R` creates the descriptive trajectory figure.
- `031_MIsensitivity.R` creates the multiple-imputation object consumed by
  `030_longmodels.R`.
- `030_longmodels.R` fits the primary and sensitivity models and produces model
  tables and figures.
- `040_practiceeffects.R` estimates and plots practice effects.
- `050_simulation_structure1.R` and `051_simulation_structure2.R` create the two
  simulation result plot objects.
- `052_simulation_plot.R` assembles the final four-panel simulation figure.

Generated files and participant-level inputs are intentionally ignored by Git.
The analysis uses fixed random seeds where simulations or imputations are
performed.
